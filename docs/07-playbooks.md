# Playbooks

Repeatable workflows. The user can say "run the Kickoff playbook", "run New page for wedding sound", etc.

## 1. Kickoff — owner discovery
Goal: replace assumptions in the business brief with owner facts.
1. Ask whether Arjun is with the owners now (live) or pasting answers he collected.
2. Go one section at a time from the open questions: Business → Gear & pricing → Proof → Brand → Later. Ask only what is still open, in plain words he can read aloud.
3. After each section, give the updated business-brief lines (marked Known, with the date) and the list of questions now closed, so Arjun can update the knowledge files.
4. If an answer changes strategy (for example, weddings are the main target, or there is a pickup location), explain the impact on the roadmap.
5. Finish with: what is now known, and what still blocks launch.

## 2. Package builder
1. Use the owners' gear list and prices only.
2. Group by use case (party, speech/meeting, live band, DJ, ceremony, outdoor), up to 3 tiers each.
3. For each package: name, good for (guests, indoor/outdoor), what's included, what the customer provides (power, table, space), "starting at" price per day, and which service levels apply (pickup / delivery and setup / full service).
4. Output a table plus copy for each package, and the content-model fields so it can go straight into the site.

## 3. New page
1. Strategist: does this page earn its place? Real demand and unique, useful content — no thin "city" pages. If not, say so and stop.
2. SEO: target search, URL, title (≤ 60 characters), meta description (≤ 155), H1, internal links, schema.
3. Copywriter: full page copy using only known facts, with clear placeholders.
4. Web lead: a ready-to-paste Claude Code prompt to build it.
5. Reviewer: list anything that would block launch.

## 4. Google Business Profile setup
1. Check Google's current rules live (they change) and cite them.
2. Decide service-area business vs storefront from the owners' answer about a pickup location. With no storefront customers visit, the address must be hidden.
3. Draft: business name exactly as on the site, primary and secondary categories, service list, service areas (up to 20), description, first photo set, and a review request text message.
4. Check name, phone and area match the website exactly.

## 5. Review request kit
Short text, email and card/QR wording asking past customers for a Google review. Never offer rewards for reviews and never write reviews for customers.

## 6. Launch checklist
- Site: builds, mobile layout checked, quote form tested end to end, click-to-call and click-to-text work on a real phone, no owner placeholders left, HTTPS on the custom domain.
- SEO: unique titles and meta, sitemap, robots, business schema valid, Search Console verified and sitemap submitted.
- Measurement: analytics with form submits and call/text clicks tracked.
- Off-site: Google Business Profile verified and linked; Yelp and Instagram linked; same name and phone everywhere.
- Proof: at least a few real photos and reviews live.

## 7. Monthly review
Ask for: quote requests (form, calls, texts), booked jobs, Google review count and rating, profile calls and website clicks, top Search Console queries. Then give 3 actions for next month.
